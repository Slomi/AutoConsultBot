# 🤖 AI-консультант для автосервиса

Telegram-бот, который 24/7 отвечает клиентам на вопросы по базе знаний бизнеса (прайс, сроки, гарантия, условия), собирает заявки и зовёт живого мастера, когда нужно.

## Возможности

- **Ответы на естественном языке** на основе GigaChat: «сколько стоит поменять колодки на Октавии?», «можно со своим маслом?»
- **Только факты из базы знаний:** бот не выдумывает цены. Если ответа нет, честно говорит и предлагает связаться с мастером
- **Помнит контекст диалога:** можно уточнять («а на заднюю ось?»)
- **Сбор заявок:** имя, телефон одной кнопкой, машина, проблема. Админ получает заявку вместе с перепиской
- **Позвать мастера:** диалог передаётся админу, тот отвечает через Reply прямо в Telegram, клиент получает ответ в боте
- **Редактор базы знаний в боте:** добавить, изменить, удалить раздел, загрузить или скачать всю базу файлом `.md`. Перезапуск не нужен
- **Статистика `/admin`:** число вопросов, процент отвеченных, заявки, частые темы и список вопросов, на которые бот не смог ответить (подсказывает, что дописать в базу)
- **LLM переключается одной строкой:** GigaChat (данные в РФ, без VPN) или любой OpenAI-совместимый API

## Стек

Python 3.11, aiogram 3, SQLite, GigaChat SDK.

## Запуск

```bash
py -3.11 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # впишите BOT_TOKEN, ADMIN_IDS, GIGACHAT_CREDENTIALS
.venv\Scripts\python bot.py
```

Ключ GigaChat: [developers.sber.ru](https://developers.sber.ru/studio) → проект GigaChat API → «Ключ авторизации». Для физлиц есть бесплатный лимит.
Корневой сертификат Минцифры, нужный для TLS до GigaChat, лежит в `certs/`.

## Настройка под бизнес

- `kb_seed.md` — стартовая база знаний, разделы начинаются с `## Заголовок`. Дальше базу удобнее править прямо в боте через `/admin` → «База знаний».
- `config.py` — название, адрес, часы работы.
- Промпт консультанта находится в `consultant.py` (`SYSTEM_PROMPT`).
